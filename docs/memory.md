# Memory Model

## Scopes

| Scope | Description | Project-bound |
|-------|-------------|---------------|
| `global` | Developer preferences shared across projects | No |
| `project` | Architecture, rules, decisions | Yes |
| `environment` | Python version, dependencies, config | Yes |
| `git` | Recent changes, commit history | Yes |
| `session` | Current task, recent actions | Yes (expires) |

## Types

- `project_rule` — Project-specific rules
- `architecture` — Architecture patterns
- `technical_decision` — Decisions with reasoning
- `coding_convention` — Coding standards
- `developer_preference` — Global preferences
- `known_issue` — Known bugs/issues
- `todo` — TODOs
- `dependency` — Dependency facts
- `environment_fact` — Environment facts
- `git_fact` — Git-derived facts
- `session_summary` — Session handoff

## Source Types

- `observed` — Extracted from project files (high trust)
- `inferred` — Inferred from analysis (medium trust)
- `user` — Explicitly provided by developer (highest trust)
- `ai` — Generated by AI agent (lower trust)

## Confidence

Each memory has a confidence score (0.0-1.0):
- `0.99` — Directly observed in config file
- `0.85` — Extracted from README
- `0.70` — Inferred from directory structure
- `0.50` — Default for user-provided facts

## Deduplication

Similar memories are automatically deduplicated using Jaccard similarity. If a new memory is >85% similar to an existing one, the existing memory is updated instead of creating a duplicate.

## Decay

Session-scoped memories expire after 7 days. Long-term memories persist indefinitely.
